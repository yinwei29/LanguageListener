# 本機 Excel／CSV 與 Sheets 同步

本機檔案是主要開始方式。下載 APK 後確認上方版本 **v0.6.0**，不需要先登入 Google。

## 從空白檔開始

1. 「教材庫 → 本機 Excel／CSV：離線開始」。如果要沿用已有的 `learning` 等來源與進度，先在「接到既有來源」選它；否則選「建立新來源」。
2. 按「建立初始 CSV」，在 Android 檔案選擇器挑選本機 Documents／Download 等可寫位置。App 建立有 UTF-8 BOM 的標準 CSV 與 15 個教材欄位（含日文、韓文），可用 Excel 開啟。
3. 查看初始化預覽，確認後連接檔案。既有來源的教材會合併入檔案，進度沿用原 sourceId。
4. 該來源按「新增此來源教材」，輸入至少兩種語言、分類、類型與程度，儲存到 App，再按「同步 App 與本機檔案」寫回檔案。
5. 按來源卡片的「開始學習這個來源」，或到播放器選擇母語／目標語及來源建立新場次。有相應離線語音包即可在飛航模式播放。

也可先用「直接新增本機教材」，不選檔就開始；這些教材請用完整 ZIP 保存。AI 設定可選本機檔案來源，審核後先儲存 App，再手動同步檔案；AI 生成仍需自己的 API 金鑰及網路。

## 連接既有 Excel／CSV

- 按「選擇 Excel／CSV」，使用 Android 系統選擇器授權單一檔案；App 不掃描其他目錄。
- 支援 `.xlsx`、UTF-8 CSV；舊 `.xls`、巨集與外部連結活頁簿先轉存一般 `.xlsx` 或 CSV。可在預覽選擇 Excel 工作表，只更新這個工作表。
- 初始化補缺少的教材欄位；有語言文字但缺 ID 的列會生成 UUID，確認後寫回，之後維持穩定。其他欄位、工作表、樣式及未修改的公式保留；不會把任意用途的表格直接當教材覆寫。
- 修改教材欄位中的公式時會拒絕寫入，請先在 Excel 另存純值版本。此功能不是完整 Excel 編輯器，不計算公式；讀取公式使用活頁簿已保存的值。
- 在 Excel 改完並儲存、關閉檔案後，按「同步 App 與本機檔案」。App 和檔案在不同教材上的修改會合併；同一 ID 兩邊不同修改會停止，請先手動調整一致後再試。
- 沒有出現在某邊的列不自動刪除教材。要停用請用 `enabled=false`，需要刪除語意可用 `status=deleted`，避免誤刪尚未同步的離線資料。
- 唯讀檔可讀取已有完整欄位與 ID 的教材；初始化需要寫入時、檔案同步時必須有寫入權限。可用「另存 App 教材為 CSV」移到可寫位置，再重新連接。

## 同步到原本的 Google Sheets

1. 本機檔案來源卡片輸入原本的 Google Sheets 網址，按「預覽本機與 Google Sheets 同步」。如這份 Sheets 已有其他來源，先將檔案接到該既有來源，避免建立重複來源。
2. Google 原生授權後，App 讀取雲端與本機，比對上次同步基準、App 與兩端教材。空白工作表會在確認畫面說明要先初始化欄位；既有不完整欄位會另外要求確認只補缺少欄位，完成後重新預覽，不建立重複來源。
3. 確認後，以 ID 新增／更新教材欄位，保留 Sheets 自訂欄位；寫回時以原始字串傳送，不把教材當 Google 公式。先重讀並檢查內容未變，完成後再驗證寫入結果。
4. 雲端成功後寫回本機檔案與 App，記錄各自基準。任一端有衝突時停止，既有學習進度不參與同步。檔案與雲端綁定來源維持手動同步；背景 CSV 下載不會覆蓋它。

Google Sheets 仍需 Sheets API／Android OAuth 設定及實際編輯權限，見 [Google／AI 設定](GOOGLE_AI_SETUP.md)。取消 Google 授權不影響本機教材、檔案或離線播放。僅 Wi-Fi 政策也適用手動雲端同步；本機讀寫不需要網路。

## 復原與備份

- 每次覆寫選取檔案前，App 在裝置私有、不備份目錄保留一份同步前原檔。遇到檔案供應程式寫入失敗，可按「另存同步前的復原副本」，或把 App 的教材另存為 CSV。
- Android SAF 檔案供應程式不保證原子寫入，Google Sheets 與本機檔案也無跨服務交易。網路中斷可能造成部分雲端批次已寫入；App 保留資料，重試以穩定 ID 更新，不以隨機 ID 重複追加。同步期間請避免其他人同時編輯同一工作表。
- 完整 ZIP 保存教材及進度；輕量 ZIP 不保存教材文字。本機 URI、檔案權限、比對基準、復原原檔與憑證不進 ZIP，換機後須重新選檔；可在既有來源選單重新連接，沿用 sourceId 與進度。
- 目前 Room 6 支援 1→2→3→4→5→6 遷移；ZIP 7 可讀 1–6，完整覆蓋還原會清除舊檔案綁定。日韓與 AI 本機來源流程見 [離線學習操作](OFFLINE_SOURCES.md)。
- 安全上限：CSV／壓縮檔 32 MiB、Excel 展開總計 64 MiB、教材工作表最多 100 欄；不以固定教材筆數限制資料。雲端讀取分頁、寫入分批。ZIP／XML 路徑、外部實體、重複 ID 與初始化格式均檢查。

實機還需驗收各家檔案供應程式的持續權限、唯讀位置、重新啟動後讀寫，並以真實 Google 帳號測試授權、配額與多端同步。自動化不替代這些驗收。
