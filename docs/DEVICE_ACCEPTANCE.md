# Android 實機與服務驗收表

以下需要 Android 手機、離線語音包及實際耳機。未勾選表示尚未在本次開發環境完成，不代表已通過。

## 安裝與離線 TTS

- [ ] 由 CircleCI artifact 或交付連結下載 debug APK（Actions 僅手動備援），在 Android 8.0 以上安裝。
- [ ] 開啟設定檢查 zh-TW、en-US、id-ID；缺少時使用系統安裝畫面下載語音包。
- [ ] 飛航模式、關閉 Wi-Fi，在全新場次首次合成三種語言，確認沒有依賴既有音訊快取。
- [ ] 分別測試母語→目標語、目標語→母語、僅目標語；各語速、1／3 次重複及 0／2 秒間隔有實際差異。
- [ ] 未安裝的離線 voice 明確報錯，沒有以網路 voice 替代。

## 背景、鎖屏與中斷

- [ ] 播放 20 筆，切換其他 app 並鎖屏至少 10 分鐘，持續跨筆播放。
- [ ] 鎖屏／通知／app 三處播放狀態、標題及上一筆／下一筆一致。
- [ ] 藍牙及有線耳機基本播放、暫停、前後筆控制；記錄型號及系統版本。
- [ ] 拔除耳機暫停；來電暫停，通話結束暫時焦點恢復後繼續；其他 app 永久取得焦點時保持暫停。
- [ ] 滑除 app 時播放不中斷；系統強制停止後不自動出聲，重新開啟恢復佇列及接近原位置。

## Sheets 與進度

- [ ] 新增兩個公開 Sheets（不同工作表 gid），手動同步後可離線搜尋與播放。
- [ ] 收藏、已學會、暫停 7／30 天、加入複習後修改 Sheets 文字，保留同一 ID，再同步，確認各狀態及播放次數保留。
- [ ] 移除一列、停用一列、重複一個 ID，確認軟刪除／停用及最後一列優先。
- [ ] 測試未公開來源、登入 HTML、斷網及錯誤 CSV；舊教材與進度不變且有錯誤提示。
- [ ] Wi-Fi 限制不使用行動網路；啟動同步與手動同步不重複排入相同工作。
- [ ] 移除再加入同一網址，確認 sourceId 與進度可沿用。

## 場次與備份

- [ ] 測試 20／50／100、自訂正整數、全部、亂數、不足筆數提示、分類／類型／難度／狀態篩選與避開近期。
- [ ] 單場次不重複，已學會與跳過期限預設排除；儲存設定不影響現有佇列。
- [ ] 完整備份匯出至 SAF 選擇的位置，換機後飛航模式匯入，預覽正確並還原教材／進度／佇列／設定。
- [ ] 輕量備份覆蓋後教材需重新同步，穩定鍵進度可接回；智慧合併衝突選較新進度。
- [ ] 取消匯入不修改資料，損毀／未知版本／路徑穿越／超量 ZIP 均拒絕。
- [ ] 小螢幕、200% 字級、TalkBack、深色模式；四頁切換及返回鍵可正常操作。

## Google 初始化與 AI 寫回（0.2.0）

- [ ] 在 Google Cloud 啟用 Sheets API，登記套件 `tw.language.listener` 及安裝 APK 的 SHA-1，設定測試帳號。
- [ ] 首次輸入私人試算表連結，Google 同意後可預覽正確工作表；取消時沒有任何寫入。
- [ ] 空白表建立 13 個欄位；既有教材表只補缺少欄位；其他用途表或僅第一列空白、下方有資料時拒絕初始化。
- [ ] 使用真實 Gemini／OpenAI 或相容模型設定產生三語教材，錯誤金鑰、配額與回應格式錯誤明確提示。
- [ ] 草稿預設不選取，分頁修改與人工確認後才寫回；中止網路後原樣重試不重複追加相同 ID。
- [ ] 寫回成功後依 Wi-Fi 政策同步，斷網可用 TTS 播放；已學會、跳過、收藏與複習不被同步重置。
- [ ] 重開 App 可繼續未寫回的草稿；ZIP 保留來源模式與非機密模型設定，不包含金鑰、token 或未審核草稿。
- [ ] 清除 Google 授權後背景不再自動取得 token；重新連接後恢復。換機與 Keystore 失效時要求重新設定，不能默默改存明文。
- [ ] CircleCI 固定 debug 簽章建置的不同版本 SHA-1 一致，更新安裝後 Google 登入仍可用。
