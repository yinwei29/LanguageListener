# 0.7.0 原生介面與 AI 本機字典

## 開始使用

1. 更新 APK 後，到「教材庫 → 新增來源或教材 → 用 AI 建立字典」。
2. 按「設定 API 金鑰與模型」，選 ChatGPT／OpenAI API、Gemini 或相容供應商，輸入自己的 API key，選擇模型並儲存。模型選擇可搜尋；API 格式、JSON 輸出與相容網址收在進階設定。
3. 回到產生頁，輸入來源名稱、主題、分類、類型、程度、語言及數量。可選繁中／英文／印尼文／日文／韓文的組合，或自訂至少兩語。
4. 完成後進入草稿審核；可按頁選取與展開編輯，確認翻譯與發音註記。人工確認後才儲存，不將 AI 生成當作已搜尋或查證。
5. App 在同一來源保存審核教材，並自動建立真正的 UTF-8 CSV 字典檔，包含 15 個教材欄位、穩定 ID 與五語文字。檔案先保存在 App 私有儲存，不需要 Google 授權或選擇外部資料夾。
6. 字典區按「儲存字典檔到手機」，由 Android 選擇儲存位置。新本機來源預設會連接另存的 CSV，繼續沿用相同來源 ID 與學習進度；可以關閉連接選項，只匯出一份副本。既有檔案來源另存不會自動改綁其他檔案。
7. 按「開始學習這個來源」。首次到設定檢查並安裝所選母語／目標語的真正離線 voice，之後可關閉網路播放、評分及複習。AI 生成及雲端同步仍需要網路與外部服務，不能宣稱離線生成。

API 金鑰只保存在裝置加密區。ChatGPT 訂閱不等於 API 額度；帳號能否使用模型、配額與 Google OAuth 設定仍需外部資源。沒有 API key 也可使用已存教材、手動新增、匯入 Excel／CSV 與離線學習。

## 介面套用

- 四區導覽保留，使用 SVG 的藍色、白色卡片、淡色背景、圓角、大型播放按鈕與清晰層級；深色模式使用對應配色。統計來自 Room，不使用 SVG 示例數字。
- 首頁分成統計、繼續學習、到期複習、快速開始及離線語音入口。
- 教材庫分開「來源列表」「來源詳情」「新增方式」「教材搜尋／編輯」；大螢幕有側邊導覽及來源／詳情雙欄。
- AI 設定、產生、審核／結果拆頁，審核只展開正在修改的一筆。已完成批次可續生，未審核不建源、不產生字典。
- 播放器分開播放、學習動作／評分、場次、進階篩選、五語語速與播放清單。場次草稿在設定子頁間共用；建立新場次後返回播放器。
- 設定分開語音包、備份、外觀及同步偏好。Google 同意與服務結果由 Activity 層統一處理，跨頁不依賴原先一直顯示的長表單。
- 畫面重建保存導覽與各頁可保存的表單狀態；API key 不放入畫面保存狀態。完整覆蓋還原多一次確認。
- Android 檔案選擇器、Google 授權、通知、鎖屏與語音包安裝仍由系統呈現，不能將 SVG 示意當成可控制所有廠牌的系統畫面。

## 字典與資料保護

Room 為主要資料，CSV 是可重建的檔案副本。每次 AI 新建或追加到本機來源，審核後自動產生／更新；手動新增／編輯也更新。外部檔案或雲端同步後，可在「CSV 字典檔」按更新；匯出時一定從目前 Room 教材重新產生。

字典按來源分批讀取 250 筆、逐列寫入，32 MiB 上限。使用 AtomicFile 保留前次完整版本，路徑由來源 ID 的 SHA-256 生成，不讓來源名稱變成檔案路徑。寫回使用者選定位置後會重新讀取核對 SHA-256，再連接檔案；檔案供應程式仍不保證跨檔案／雲端交易。

來源及教材以 sourceId + itemId 保留進度。CSV 保存教材，學習紀錄與複習排程請用完整 ZIP 備份；輕量 ZIP 沒有教材文字。API key、token、URI 存取權、語音包、未審核草稿及衍生 CSV 不放入 ZIP；完整 ZIP 的教材可在還原後重新建立 CSV。

若教材已儲存但字典寫入失敗，教材不回滾或丟棄，畫面提供重新建立；不能顯示尚未成功的檔案為已完成。重複確認同一草稿不覆蓋後續教材修改與學習進度。移除來源後不允許匯出它的舊快取，備份還原會清除舊衍生檔。

本次不改 Room 6／ZIP 7 格式，可直接由 0.6.0 更新。

## 驗證範圍

新增資料測試涵蓋審核產生實際 CSV、五語／引號／換行／BOM、選取內容與穩定 ID、CSV 重匯入後建立日韓離線佇列、進度保留、513 筆跨頁、路徑限制、過時來源、檔案失敗後重試、覆寫失敗保留前一完整字典，以及真實來源查詢與統計。

Compose／Robolectric 整合測試走教材庫、AI 設定、審核資料發佈、字典頁及畫面重建，確認不依賴 Google 授權。JVM 沒有 Android 媒體服務 binder，該介面測試明確模擬服務無法連接；只驗證導覽、字典及資料流程，不冒充實際語音、鎖屏、耳機或 Google／AI 帳號驗收。

實機仍需驗收飛航模式首次語音合成、鎖屏／耳機、SAF 持續權限與不同檔案供應程式、鍵盤／大字級／平板及真實服務帳號。
