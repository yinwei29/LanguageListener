# 0.6.0 本機來源、AI 建材與日韓離線學習

## 最快開始

1. 到「教材庫」最上方的「AI 新增來源與教材」，選「用 AI 建立新來源」，輸入來源名稱。
2. 展開 AI 設定，選 ChatGPT／OpenAI API（或既有 Gemini／相容供應商），填入自己的 API key，選擇或輸入帳號支援的模型並儲存。ChatGPT 訂閱不等於 API 額度；生成需要網路與 API 帳號。
3. 輸入主題、數量、程度，選繁中／日文、繁中／韓文、日文／韓文、原三語、五語或自訂至少兩語。單批最多 100 筆，內部逐批保存，可中斷後繼續。
4. 產生後逐筆審核、修改並選取，按「建立來源並儲存審核教材」。此時才建立本機來源，不需要 Google 授權，不建立遠端檔案。AI 回傳的來源網址及 ID 不作為可信來源；教材 ID 由 App 產生。
5. 按「開始學習這個來源」，只用該來源建立場次並開啟播放器。保留原本的筆數、語速、重複與朗讀方向；自動選該來源實際具有的語言配對，清除舊分類等篩選。停用、刪除及暫停教材仍按既有規則排除。
6. 首次先到設定「檢查／安裝離線語音包」，安裝所選兩語的真正離線 voice。之後教材文字、朗讀合成、評分、到期複習及統計均在本機，不需要 AI 或 Google 連線。Android TTS 合成 WAV，既有 Media3 前景服務負責背景、鎖屏、通知及媒體鍵。

也可以不使用 AI：建立 CSV 或選擇本機 `.xlsx`／UTF-8 CSV，確認初始化後新增教材；來源卡片可直接開始學習。檔案需放在真正可離線讀取的位置，雲端檔案供應程式未下載的檔案不能視為本機檔案。

## 來源與檔案

- 來源卡片可重新命名，sourceId、教材 ID 與進度不變。播放器也可明確篩選單一來源。
- AI 建立的本機來源與原本「我的本機教材」可「另存並連接 CSV」：Android 選擇新檔位置後，以原來源 ID 連接檔案，原教材與學習狀態保留。匯出不需要 Google。
- 修改先存 App，再按同步本機檔案寫回；衝突會停止，不會猜測覆蓋。同一來源還可選擇連接原本 Google Sheets，沿用既有預覽、授權及確認同步流程。
- 詳細檔案與雲端規則見 [本機文件](LOCAL_DOCUMENTS.md)。Google Sheets 仍須外部 OAuth、Sheets API 及檔案編輯權限。

## 五語資料與相容性

- 新增 `ja-JP`、`ko-KR`，涵蓋 AI、人工編輯、檔案、搜尋、雲端、語音與完整 ZIP；各有獨立語速。介面語言仍為繁中／英文／印尼文，教材語言與介面語言分開。
- 新建初始 CSV 為 15 欄；舊檔仍可用，寫回日韓教材時才追加所需欄位。初始化日韓文字且缺 ID 的檔案可補 UUID。Excel 保留未知欄位、其他工作表、樣式與未變更公式。
- 新 Google 來源初始化 15 欄。原本的工作表需要日韓欄位時，先確認補欄再寫入；不能在缺欄時默默丟棄日韓翻譯。
- Room 6，5→6 新增兩個空字串欄位，既有教材、進度、複習、佇列及草稿保留。ZIP 7 保留五語與來源篩選／語速，讀取 1–6；舊 App 不能讀新版 ZIP。
- AI 待建立來源只存在裝置草稿，未審核不進來源／教材表，也不進 ZIP；完整覆蓋還原會清除草稿。憑證、語音包、檔案存取權與 URI 綁定仍排除在 ZIP 外，換機須重新設定及選檔。

## 實機驗收

- 從 0.5.0 直接更新，確認來源、文字、評分與進度保留。
- AI 新建日文、韓文來源；取消審核不產生來源，重開後可繼續，確認後可直接學習，不混入示範教材。
- 關閉網路，首次合成日韓語音、鎖屏持續播放、耳機暫停／下一筆；缺離線 voice 時應提示，不能退回網路 voice。
- 新來源另存並連接 CSV、Excel 往返修改、重開、雙端衝突及原 Sheets 同步，穩定 ID 與複習排程不變。
- 完整 ZIP 換機還原日韓教材與進度；重新安裝語音包並選取檔案。輕量 ZIP 不含教材文字，不能當作完整離線換機包。

自動化不能替代實機、真實 API／Google 帳號與檔案供應程式驗收；目前沒有連接 Android 手機或這些服務的實際測試帳號。
