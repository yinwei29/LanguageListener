# Codex 分階段施工與驗收

## Phase 1 — 離線 MVP（第一優先）
1. 初始化 Android Kotlin/Compose/Material 3 專案與 Gradle Wrapper。
2. Room 教材、來源、進度、場次、設定資料表；提供不含私人資訊的三語示範教材。
3. 首頁、播放器、教材庫、設定四頁。
4. Android TTS 語言切換、離線語音檢查、語速/重複/延遲。
5. MediaSession、背景服務、通知、鎖屏、耳機基本控制、音訊焦點。
6. 順序/亂數、數量、自訂篩選、已學會/跳過/收藏/複習、佇列持久化。
7. 多來源公開 Google Sheets CSV 同步、錯誤回復。
8. SAF 無加密 ZIP 輕量/完整備份、匯入預覽、覆蓋/合併。
**驗收：** 斷網且鎖屏能播放已下載教材；重啟保留狀態；備份可還原；assembleDebug 成功並可安裝 APK。

## Phase 2 — 同步與體驗
- 私人 Sheets OAuth 讀取、增量同步/刪除策略、僅 Wi-Fi 設定、效能測試。
- 語音包安裝指引、耳機/來電恢復、深色模式、繁中/英/印尼介面本地化。
**驗收：** 同步失敗不丟進度；大量教材不造成明顯卡頓。

## Phase 3 — AI 教材
- Gemini/OpenAI 相容 BYOK、Key 安全儲存、生成/去重/驗證/人工審核。
- Sheets 授權寫回、API 用量與錯誤顯示；明確區分生成與搜尋。
**驗收：** 未設定 API Key 時主要功能正常；密鑰不外洩；未審核教材不寫回。

## Phase 4 — 學習優化
- 間隔複習、學習統計、優先級、更多語言。
**驗收：** 演算法有單元測試，教材同步不丟失進度。

## Phase 5 — CI 與交付
- GitHub Actions：Gradle test/lint/assembleDebug，提供 APK artifact，設定合理保存天數。
- Android 實機測試：背景播放、離線 TTS、耳機媒體鍵、換機匯入。
- 更新 README、資料庫遷移、公開儲存庫安全掃描。

## 每階段提交要求
獨立 PR、列出完成範圍、編譯/測試結果、已知限制與下一階段待辦。不要一次宣稱所有功能已完成。
