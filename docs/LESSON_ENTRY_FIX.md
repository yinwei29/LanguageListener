# 0.4.0：新增教材與空白工作表

「新增來源」只是連接遠端教材，不能把空白試算表自動變成教材。CSV 回應為空時，App 必須保留快取與學習進度，不能把它視為已初始化的空快照而刪除教材。

本機檔案的主要入口與同步方式另見 [Excel／CSV 操作說明](LOCAL_DOCUMENTS.md)。

## 不使用外部服務就能開始

1. 安裝 `LanguageListener-0.4.0-debug.apk`，確認上方顯示 **v0.4.0**。
2. 「教材庫 → 直接新增本機教材 → 新增教材」，填寫至少兩種語言；可選分類、單字／短語／句子、程度。
3. 按「儲存教材」，到播放器選擇已填的母語／目標語並建立新場次。安裝相應離線 TTS 語音包後可斷網播放。
4. 搜尋本機教材可按「編輯本機教材」。編輯沿用穩定 ID，不重置已學會、收藏、播放次數或既有佇列；新文字在下次建立場次載入。
5. 本機教材不會寫回 Google Sheets，也不參與遠端同步。請用**完整 ZIP** 保存文字；輕量 ZIP 不含教材，不能從 Sheets 找回本機新增的內容。

## 使用 Google Sheets 與 AI

- 若工作表空白，使用「連接／儲存並初始化」或該來源的「初始化這個工作表／授權新增教材」。Google 授權並確認預覽後只補缺少欄位，不覆寫教材。
- 確認連結的 `gid` 對應正確分頁；公開 CSV 仍需可下載的分享／發布設定。
- 初始化後在 AI 區設定自己的 API 金鑰，產生、審核並選取後確認寫回，再同步手機。Google Cloud Android OAuth 與真實 API 額度仍是外部設定，見 [設定文件](GOOGLE_AI_SETUP.md)。
- 新版空白 CSV 訊息會說明如何初始化或直接新增本機教材。同步拒絕空白 CSV，原有教材與進度保留。
