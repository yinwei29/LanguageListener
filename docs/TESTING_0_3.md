# 0.3.0 整合測試指南

此 APK 包含前幾次交付的離線播放、背景媒體服務、公開／私人 Sheets、初始化、AI 草稿審核寫回與 ZIP 備份，以及本次三語介面。先測無帳號流程，再測外部服務，可以一次回報整批結果。自動測試結果見 PR；以下實機項目未勾選前不表示已驗收。

## 不需要外部帳號

1. 安裝 APK，設定頁檢查離線語音包。首次下載語音包需要網路與支援該語言的 TTS 引擎；完成後不需要任何 API 金鑰。
2. 使用內建示範教材，測試首頁四種快速開始。到播放器改母語／目標語、語序、語速、重複、間隔、循環、場次筆數、亂數、分類／類型／難度、避開近期與優先複習，建立場次確認實際行為。設定儲存只影響下個場次。
3. 標記學會、收藏、加入複習、暫停 7／30 天；重開 App，確認教材狀態與原佇列保留，沒有自行出聲。
4. 設定頁依序切換「繁體中文」「English」「Bahasa Indonesia」。檢查四頁、選單、確認對話框、Google／AI 設定與 ZIP 預覽；介面、日期與語速小數隨語言改變，教材文字、分類及 Sheets 欄名保留原文。語言保存於 Room，也納入備份。
5. 播放中切換語言／深色模式，確認服務仍播放同一場次；關閉螢幕連續聽至少 10 分鐘，從通知與鎖屏操作。測試拔耳機、媒體鍵及來電，細節見 [實機驗收表](DEVICE_ACCEPTANCE.md)。
6. 匯出完整 ZIP，做幾次進度變更，預覽後取消匯入確認無變更，再分別測試智慧合併與覆蓋。完整備份可在飛航模式還原教材；輕量備份需重新同步教材。換機須重裝離線語音包。
7. 若已有 0.1／0.2 資料，直接更新同簽章 APK，確認進度與佇列保留。Room 自動執行 1→2→3 或 2→3；舊版 ZIP 1／2 可匯入，新版 ZIP 3 保存介面語言，舊備份預設繁中。舊 App 不能讀新版 ZIP。
8. 小螢幕與 200% 字級檢查可捲動，開啟鍵盤仍能操作；開 TalkBack 檢查審核勾選框有對應筆數標籤。

公開 CSV 來源不需 OAuth：新增一個可公開下載的 Sheets 來源，確認下載後可斷網使用；修改文字但保留 ID，再同步確認進度保留。不可公開下載時應報錯並保留本機教材。

## 需要一次性外部設定

- **私人 Sheets 與初始化／寫回**：Google Cloud 啟用 Sheets API，Android OAuth 登記套件與目前 APK 的 SHA-1；使用有該工作表編輯權限的 Google 帳號。
- **AI 生成**：自己的 Gemini／OpenAI／相容 API 金鑰與可用模型／額度。只產生草稿，人工選取與確認後才附加到 Sheets，隨後依網路政策同步；沒有金鑰仍能用全部離線學習功能。
- **CircleCI 雲端 APK**：在 CircleCI 授權並連接 GitHub 專案。設定檔與本機同一建置腳本已備妥，尚無已授權的 CircleCI 帳號可代為完成首次雲端 pipeline。GitHub Actions 維持手動備援。

連接步驟見 [Google／AI 設定](GOOGLE_AI_SETUP.md) 與 [CI](CI.md)。不要將金鑰或 OAuth token 貼入公開 issue。除使用者明確確認外，程式不覆寫既有 Sheets 教材；初始化先預覽，只補缺少欄位。

## 語言資源維護

`tools/ui_translations.json` 是三語文案來源；執行 `python3 tools/generate_localizations.py` 更新 Android resources 與舊訊息對照，`--check` 檢查漏翻、參數及產物一致性。CircleCI 腳本會在 Gradle 前執行檢查。後端保留既有診斷格式以相容已存錯誤；顯示時翻譯，外部 SDK／系統／未知診斷保留原文。使用者教材不經訊息翻譯器。

回報問題請附 APK 版本、手機與 Android、介面語言、TTS 引擎、重現步驟及實際結果。Google／AI 問題只提供去除憑證的錯誤訊息。
